# TToTA AI 서비스 소개

TToTA AI는 RAG(Retrieval-Augmented Generation, 검색 증강 생성) 기반의 AI 챗봇 서비스입니다.
사용자가 질문하면 미리 준비된 문서 데이터에서 관련 내용을 검색하고, 그 내용을 근거로 답변합니다.

## 주요 기능
- 문서 기반 답변: dataset 폴더의 문서를 Upstage Embedding API로 임베딩하여 Supabase(pgvector)에 저장하고, 질문과 의미적으로 가까운 문서를 찾아 답변에 활용합니다.
- 최신 정보 검색: 뉴스, 날씨처럼 최신 정보가 필요한 질문은 Tavily MCP 웹검색 결과를 참고합니다.
- 모델 선택: Claude, ChatGPT, Gemini 중 원하는 LLM을 선택할 수 있습니다.
- 대화 기록: Google 계정으로 로그인하면 채팅방별 질문, 답변, 생성 시간이 Supabase에 저장됩니다.

## 사용 방법
1. 랜딩페이지에서 "Google로 시작하기" 버튼을 눌러 로그인합니다.
2. 상단에서 사용할 AI 모델을 고릅니다.
3. 질문을 입력하면 답변 아래에 참고한 문서와 웹 출처가 표시됩니다.
4. 왼쪽 사이드바에서 이전 대화를 다시 열거나 삭제할 수 있습니다.
